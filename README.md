## 🏗️ Featured Projects

### ⚡ Isango Student Risk Pipeline — AWS Serverless Data Engineering
End-to-end serverless pipeline on AWS that ingests multi-source student data, runs a PySpark ETL job on AWS Glue to classify learners as LOW/MEDIUM/HIGH risk, and exposes results via a REST API.

**Stack:** `AWS Glue` `PySpark` `Lambda` `DynamoDB` `S3` `API Gateway` `CodePipeline` `CodeBuild` `Docker` `ECR` `IAM`

### 🧠 Isango Early Warning System — UCT Honours Capstone
AI-powered predictive analytics platform to reduce high school dropout rates in South Africa. Uses Google Gemini AI for risk prediction and Twilio for SMS notifications to counsellors.

**Stack:** `Java Spring Boot` `MongoDB` `PostgreSQL` `Node.js` `Gemini AI` `Twilio`

### 🧩 Java Spring Boot Microservices Ordering System
Production-grade ordering system with Inventory, Product, and Order services. Integrated API Gateway, Eureka Discovery, Resilience4j circuit breaker, and Keycloak auth.

**Stack:** `Java` `Spring Boot` `Keycloak` `Resilience4j` `API Gateway` `Eureka`
